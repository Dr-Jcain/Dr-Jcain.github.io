Concepto de variable

Una variable relaciona un nombre con un espacio de almacenamiento capaz de contener un valor de determinado tipo. Durante la ejecución del programa ese valor puede cambiar.

02

Identificadores

El nombre permite referirse a la información sin memorizar direcciones

Un identificador es un nombre creado para referirse a elementos del programa: variables, constantes, funciones, estructuras, etc. En int edad = 20;, edad es el identificador.

La computadora trabaja con direcciones; el programa trabaja con nombres. El compilador relaciona ambos niveles.

No confundir

Nombre ≠ valor ≠ dirección

La variable edad puede conservar su nombre y su dirección mientras su contenido cambia de 20 a 21.

Problemas

Lee declaraciones como información de memoria

Problema 1Analiza int contador = 0;.+

Tipo: int. Identificador: contador. Valor inicial: 0. La variable puede recibir posteriormente otro entero representable.

Problema 2Después de contador = contador + 1;, ¿qué ocurre?+

Se calcula el nuevo valor y se escribe en el espacio de memoria asociado a contador. El identificador sigue siendo el mismo.

Problema 3¿Puede una variable char letra guardar directamente 3.1416?+

No es el tipo adecuado. El tipo establece cómo se interpreta y almacena el contenido; para un real se utiliza un tipo de coma flotante.

Problema 4¿La dirección forma parte del identificador?+

No. El identificador es el nombre usado en el código. La dirección corresponde a la ubicación de almacenamiento asociada durante la ejecución.
