Conversiones entre sistemas binario, octal, decimal y hexadecimal

La misma cantidad puede representarse con símbolos distintos según la base del sistema numérico. En esta clase usaremos el valor posicional para convertir hacia decimal y divisiones sucesivas para convertir desde decimal.

Sistemas numéricos

02

Sistema posicional

El valor de un símbolo depende de dónde se encuentra

Los sistemas que utilizaremos son posicionales. Cada casilla tiene un peso. Comenzando por la derecha, la primera posición vale \(b^0\), la siguiente \(b^1\), después \(b^2\), y así sucesivamente.

\[ d_n\,d_{n-1}\cdots d_2\,d_1\,d_0 \quad\Longrightarrow\quad d_n b^n + \cdots + d_2 b^2+d_1b^1+d_0b^0 \]

La base \(b\) es 10 para decimal, 2 para binario, 8 para octal y 16 para hexadecimal.

Lectura rápida

Empieza siempre por la derecha

La posición más a la derecha siempre tiene exponente cero. Al moverte una casilla hacia la izquierda, el exponente aumenta en uno.

No importa la base: el patrón de exponentes siempre es \(0,1,2,3,\ldots\) de derecha a izquierda.

03

Hacia decimal

Multiplicar cada dígito por el valor de su posición y sumar

El procedimiento es el mismo para binario, octal y hexadecimal. Sólo cambia la base utilizada en las potencias.

Binario → decimal

\(1010111_2\)

\[ 1(2^6)+0(2^5)+1(2^4)+0(2^3)+1(2^2)+1(2^1)+1(2^0) \]

\(64+0+16+0+4+2+1=\boxed{87_{10}}\)

Octal → decimal

\(157_8\)

\[ 1(8^2)+5(8^1)+7(8^0) \]

\(64+40+7=\boxed{111_{10}}\)

Hexadecimal → decimal

\(2B7_{16}\)

\[ 2(16^2)+11(16^1)+7(16^0) \]

\(512+176+7=\boxed{695_{10}}\)

04

Desde decimal

Dividir sucesivamente entre la base y leer los residuos al revés

Para realizar la conversión inversa, dividimos el número decimal entre la base del sistema destino. El residuo es un dígito del resultado. El cociente se vuelve a dividir y el procedimiento continúa hasta que el cociente sea cero.

Número decimal

Se divide entre la base destino.

→
Residuos

Se leen de abajo hacia arriba.

Regla esencial

Los residuos se producen desde el dígito menos significativo hacia el más significativo; por eso se escriben en orden inverso.

Problema 4Convierte \(156_{10}\) a binario, octal y hexadecimal+

Realiza tres cadenas de divisiones sucesivas: entre 2, 8 y 16.

1
Base 2

Los residuos leídos de abajo hacia arriba forman \(\boxed{10011100_2}\).

2
Base 8

\(156\div8=19\) residuo 4; \(19\div8=2\) residuo 3; \(2\div8=0\) residuo 2. Resultado: \(\boxed{234_8}\).

3
Base 16

\(156\div16=9\) residuo 12 = C; \(9\div16=0\) residuo 9. Resultado: \(\boxed{9C_{16}}\).
