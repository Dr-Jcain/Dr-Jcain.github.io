Palabras reservadas del lenguaje

Los nombres creados por el programador se llaman identificadores. Las palabras reservadas o palabras clave pertenecen al propio lenguaje C y no pueden utilizarse como nombres de variables, constantes o funciones.

01

Elementos de un programa

Identificadores y palabras reservadas son categorías diferentes

Identificador

Nombre creado por el programador para referirse a una variable, constante, función u otro elemento permitido.

contadortemperaturacalcularAreadato_1

Palabra reservada

Palabra con significado definido por el lenguaje. El programador no puede reutilizarla como identificador.

intifelsewhilereturnconst
Regla léxica básica

Un identificador de C comienza con una letra o guion bajo y después puede contener letras, dígitos o guiones bajos. Además, no debe coincidir con una palabra reservada.

03

Problemas

Clasifica nombres y palabras del lenguaje

Problema 1Clasifica: int, edad, return, promedio.+

int y return son palabras reservadas. edad y promedio pueden ser identificadores.

Problema 2¿Por qué 3temperaturas no es válido?+

Porque comienza con un dígito. Un identificador debe comenzar con una letra o guion bajo.

Problema 3¿Por qué dato-final no es válido?+

Porque el guion - es un operador y no forma parte de los caracteres permitidos en un identificador.

Problema 4Propón un nombre válido para almacenar el número de alumnos.+

Ejemplos: numeroAlumnos, num_alumnos o alumnos. Conviene que el nombre describa el dato.
