01

Arquitectura básica

La CPU procesa; la memoria conserva datos e instrucciones

CPU

Unidad central de procesamiento

Busca instrucciones, las interpreta y ejecuta operaciones aritméticas, lógicas y de movimiento de datos.

RAM

Memoria principal

Está formada por posiciones direccionables. Cada posición almacena información que puede ser leída o escrita durante la ejecución.

E/S

Entrada y salida

La entrada introduce información al sistema; la salida comunica resultados hacia el exterior.

Dirección de memoria

Es el identificador numérico de una posición de memoria. Para acceder a un dato no basta conocer su valor: la CPU debe indicar también dónde se encuentra.

02

Comunicación

Tres buses cumplen funciones diferentes

A

Bus de direcciones

Indica la posición de memoria que se desea utilizar. En el ejemplo, la CPU coloca una dirección como 0x1003.

D

Bus de datos

Transporta la información que se escribe o la información que se recupera de la memoria.

C

Bus de control

Indica qué operación debe realizarse, por ejemplo READ para leer o WRITE para escribir.

Problema 2¿Qué cambia si la CPU quiere leer la dirección 0x1002?+

La dirección sigue siendo 0x1002, pero el control pasa a READ. El dato viaja ahora desde la memoria hacia la CPU.

Problema 3Un teclado envía un carácter y luego se muestra en pantalla. Clasifica entrada, procesamiento y salida.+

Teclado: entrada. CPU y memoria: procesamiento/almacenamiento. Pantalla: salida.

Problema 4¿Por qué dos datos iguales pueden estar en direcciones distintas?+

Porque una dirección identifica la posición, no el contenido. Dos casillas diferentes pueden contener exactamente el mismo valor.
