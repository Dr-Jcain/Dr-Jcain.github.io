Concepto de constante

Una constante representa un dato cuyo valor debe permanecer fijo después de su inicialización. En esta introducción trabajaremos con objetos declarados con const para contrastarlos directamente con una variable.

Problemas

Clasifica y justifica

Problema 1const float PI = 3.1415926f;: identifica cada elemento.+

const: calificador; float: tipo; PI: identificador; 3.1415926f: valor inicial.

Problema 2¿Por qué conviene usar una constante para un límite fijo?+

Porque expresa la intención del programa y evita reasignaciones accidentales a través de ese objeto.

Problema 3¿Una constante deja de tener tipo de dato?+

No. Sigue teniendo un tipo que determina cómo se representa y almacena su valor.

Problema 4¿Qué diferencia hay entre inicializar y reasignar?+

Inicializar proporciona el primer valor al crear el objeto. Reasignar intenta escribir un valor posterior; eso es válido para una variable, pero no para el objeto const usado aquí.
