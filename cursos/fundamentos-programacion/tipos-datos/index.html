Tipos de datos: entero, real y carácter

Un tipo de dato define cómo se representa y almacena la información. En C, el tipo determina qué valores puede representar un objeto, cómo se interpretan sus bits y qué operaciones tienen sentido sobre él.

Precisión de la definición

El estándar de C no obliga a que int mida 4 bytes ni a que float use IEEE 754. En las visualizaciones de esta clase asumiremos el caso habitual: byte de 8 bits, int de 32 bits y float IEEE 754 de simple precisión.

Sobre ASCII

Con 8 bits existen 256 patrones. El ASCII estándar define 128 códigos (0–127); otros valores dependen de codificaciones o extensiones. Para comprender char, lo importante aquí es asociar un carácter con un código almacenado en un byte.

Problemas

Practica las representaciones

Problema 1Representa −5 en complemento a 2 de 8 bits.+

5 = 00000101. Invertir: 11111010. Sumar 1: 11111011.

Problema 2¿Qué código decimal almacena 'A' en ASCII?+

El código ASCII de 'A' es 65, cuya representación binaria de 8 bits es 01000001.

Problema 3Separa los campos de un float IEEE 754.+

Un binary32 contiene 1 bit de signo, 8 bits de exponente con sesgo 127 y 23 bits de fracción. La mantisa efectiva de números normales incluye además un 1 implícito.

Problema 4¿Por qué no debe afirmarse que todo int de C siempre mide 4 bytes?+

Porque su tamaño depende de la implementación y arquitectura. Cuatro bytes es un caso muy común, pero no una obligación general del lenguaje C.
