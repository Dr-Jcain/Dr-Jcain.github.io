Objetivo de trabajo

¿Qué debe quedar claro?

Trabajar de forma trazable desde que aparece una actividad hasta que su cambio se integra en main.

Guía de la clase

Conceptos y reglas operativas

main estable

Después de establecer la Design Baseline no se desarrolla directamente sobre main.

Issue

Una actividad relevante debe tener título claro, referencia WBS, descripción, responsable, criterio de terminado, Sprint y evidencia pertinente.

Branch

Cada actividad relevante se desarrolla en una rama independiente, por ejemplo feature/17-pwm-generator.

Pull Request

Debe explicar qué se realizó, qué Issue resuelve, archivos modificados, verificaciones y pendientes.

GitHub Project

El tablero debe reflejar el estado real: Backlog, To Do, In Progress, Review, Done y Blocked.
