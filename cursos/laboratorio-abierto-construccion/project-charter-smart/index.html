01

Project Charter

Qué proyecto tenemos y bajo qué condiciones inicia

El template proporcionado organiza el Charter mediante Executive Summary, Project Goal, Deliverables, Business Case/Background, Benefits/Costs/Budget, Scope and Exclusion, Project Team y Measuring Success.

Idea operativa

El objetivo debe ser SMART

Specific, Measurable, Attainable, Relevant y Time-bound.

02

Objetivo SMART

Cinco preguntas para depurar el objetivo

1Specific¿Qué se pretende construir?
2Measurable¿Cómo sabremos si se logró?
3Attainable¿Es viable con recursos/tiempo?
4Relevant¿Responde al proyecto?
5Time-bound¿Cuándo debe alcanzarse?
03

Alcance y éxito

Un Charter reduce ambigüedad antes de ejecutar

El alcance debe señalar explícitamente qué actividades/resultados forman parte del proyecto y cuáles quedan fuera. Los criterios de éxito deben expresarse de manera suficientemente concreta para poder evaluarse después.

Idea operativa

Use el template como estructura, no como respuesta

El ejemplo adjunto ilustra cómo llenar un Charter, pero los contenidos deben derivarse del proyecto real del equipo, no copiarse del caso Plant Pals.
