01

Regla de trabajo

Cada integrante debe contribuir con su propia cuenta

No se permiten cuentas compartidas. Cada integrante debe utilizar un correo asociado a su cuenta, comunicar su usuario al Project Leader y verificar que sus contribuciones aparecen atribuidas correctamente.

Idea operativa

Visibilidad pública o privada

La decisión depende de resultados no publicados, información confidencial, propiedad intelectual, posibilidades de protección y restricciones indicadas por el mentor/supervisor.

02

Estructura

Una estructura adaptable a la naturaleza del proyecto

README.md /design-baseline /project-management /charter /wbs /raci /risks /schedule /docs /technical /src /hardware /software /cad /bom /tests /evidence
03

README principal

La portada técnica del repositorio

Como mínimo debe indicar nombre del proyecto, descripción, objetivo general, mentor, Project Leader, integrantes, estado actual, estructura del repositorio, Sprint o versión actual e instrucciones necesarias para consultar o reproducir la solución.

Idea operativa

La estructura no es rígida

Un proyecto electrónico puede priorizar /hardware; uno computacional /software o /src; uno mecánico /cad. Debe representar el proyecto real.
