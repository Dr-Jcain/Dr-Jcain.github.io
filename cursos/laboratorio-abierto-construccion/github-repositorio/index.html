GitHub: cuentas, repositorio y README

Configuración del repositorio único, cuentas individuales, visibilidad y README principal.

ComenzarVer evidencia

Objetivo de trabajo

¿Qué debe quedar claro?

Configurar GitHub como herramienta real de control de versiones, colaboración y trazabilidad; no como simple almacenamiento final de archivos.

Guía de la clase

Conceptos y reglas operativas

Cuentas individuales

Cada integrante utiliza su propia cuenta, nombre y correo asociados. No se permiten cuentas compartidas.

Visibilidad

El repositorio puede ser público o privado. Mentor y supervisor deciden considerando confidencialidad, propiedad intelectual o resultados no publicados.

Un repositorio principal

Todo el equipo trabaja sobre el mismo repositorio mediante sus propias cuentas.

README

Debe permitir comprender rápidamente nombre, descripción, objetivo, mentor, Project Leader, integrantes, estado, estructura, Sprint actual e instrucciones pertinentes.
