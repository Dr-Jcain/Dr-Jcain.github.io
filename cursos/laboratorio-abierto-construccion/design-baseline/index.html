Establecer el punto técnico de partida que recibe Construcción para poder identificar posteriormente qué cambió durante la materialización.

Guía de la clase

Conceptos y reglas operativas

Design Baseline

Representa el estado del diseño recibido desde Laboratorio Abierto: Diseño.

Contenido

Puede incluir memoria, requisitos, diagramas, esquemáticos, planos, CAD, simulaciones, algoritmos, código, BOM preliminar, modelos matemáticos y especificaciones.

README interno

Debe registrar proyecto, procedencia, fecha, versión, mentor, Project Leader, estado del diseño, documentos recibidos, pendientes y restricciones.

Versión congelada

Una vez verificada, se crea la etiqueta design-baseline-v1.0.
