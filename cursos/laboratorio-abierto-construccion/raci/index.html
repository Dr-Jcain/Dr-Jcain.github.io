01

Matriz RACI

Una actividad, una asignación explícita

R — Responsible: realiza el trabajo. A — Accountable: responde por el resultado. C — Consulted: aporta información/criterio antes de actuar. I — Informed: debe conocer el avance o resultado.

Idea operativa

Los roles pueden cambiar entre actividades

RACI no significa que un integrante mantenga exactamente la misma letra durante todo el proyecto. La asignación depende de cada actividad.

03

Consistencia

La RACI debe coincidir con la ejecución

Si la RACI asigna una actividad a una persona, el Issue y el historial de GitHub deberían mostrar evidencia coherente con esa responsabilidad. Las discrepancias deben poder explicarse y, si el cambio fue real, actualizarse.

Idea operativa

Señales de problema

Actividades sin R, demasiados A, responsables que no aparecen en la evidencia o una RACI que nunca cambia aunque cambie el proyecto.
