# Laboratorio Abierto: Construcción — JCain Engineering

Materia integrada al sistema automático del portal. El temario se declara en `course.json`; cada carpeta inmediata con `index.html` representa una clase publicada y `scripts/build_site.py` actualiza automáticamente contadores, navegación y `assets/data/site-data.*`.

## Estructura
- Unidad I: inicio y configuración del proyecto.
- Unidad II: Sprint I — planificación.
- Unidad III: Sprint II — seguimiento, evaluación y adaptación.
- Unidad IV: Sprint III — consolidación y transición hacia Pruebas.

Los formatos descargables se encuentran en `recursos/`.
