Eficiencia de un algoritmo

Dos algoritmos pueden resolver correctamente el mismo problema y requerir cantidades muy distintas de tiempo y memoria. El análisis de eficiencia estudia esos recursos y, en particular, cómo cambian cuando aumenta el tamaño de la entrada.

01

Eficiencia

Tiempo y memoria como recursos computacionales

Cuando varios algoritmos resuelven el mismo problema, no basta con verificar que todos produzcan la respuesta correcta. También interesa comparar los recursos que requieren.

T

Tiempo

Cantidad de trabajo necesario para completar la ejecución.

M

Memoria

Cantidad de almacenamiento requerido durante la ejecución.

Objetivo del análisis

Comparar algoritmos con independencia de una prueba aislada

Una medición concreta puede cambiar al usar otra computadora o una implementación distinta. El análisis teórico busca describir el comportamiento del algoritmo en función del tamaño de la entrada.

02

Tamaño de entrada

La función T(n)

T(n)

Representa cómo cambia la medida del tiempo requerido por el algoritmo cuando cambia el tamaño n de los datos de entrada.

El significado de n depende del problema. Puede ser, por ejemplo, el número de elementos de un arreglo que se desea ordenar o la dimensión de matrices que se desean multiplicar.

Importante

En el análisis teórico, T(n) no se expresa simplemente en segundos o milisegundos. Interesa principalmente la forma de la función y cómo aumenta cuando crece n.

03

Dos enfoques

Análisis a priori y medición a posteriori

A priori

Medida teórica

Se obtiene una función que acota el tiempo de ejecución para tamaños de entrada dados. El objetivo es estudiar el algoritmo sin depender de una computadora específica.

A posteriori

Medida experimental

Se ejecuta una implementación con datos concretos en una computadora determinada y se registra el tiempo real de ejecución.

04

Principio de invarianza

La implementación puede cambiar constantes sin cambiar la naturaleza del crecimiento

Para dos implementaciones de un mismo algoritmo, con tiempos T₁(n) y T₂(n), el principio de invarianza establece la existencia de una constante real c > 0 y un n₀ tales que, para n suficientemente grande, una de las funciones puede quedar acotada por una constante multiplicativa de la otra:

T₁(n) ≤ c T₂(n),    para n ≥ n₀

Por eso, al comparar eficiencia temporal, la forma de crecimiento de T(n) es más importante que una diferencia producida únicamente por un factor constante.

Problemas de repaso

Interpretación de eficiencia y T(n)

Problema 1Un algoritmo ordena un arreglo de 250 elementos. ¿Qué representa n?+
1
Tamaño de entrada

La entrada contiene 250 elementos.

2
Resultado

Para esa ejecución, n = 250.

Problema 2Se ejecuta un programa diez veces y se registran milisegundos. ¿Qué tipo de estudio es?+
1
Observación

Se realizan ejecuciones reales en una computadora.

2
Clasificación

Es un estudio a posteriori.

Problema 3Sin ejecutar el programa se obtiene una función que acota el tiempo. ¿Qué tipo de estudio es?+
1
Observación

La evaluación se realiza mediante una función teórica.

2
Clasificación

Es un estudio a priori.

Problema 4Si T₁(n)=2n y T₂(n)=6n, calcula T₂(n)/T₁(n).+
1
Cociente

T₂(n)/T₁(n)=6n/(2n)=3.

2
Interpretación

En este ejemplo las funciones difieren por un factor constante de 3.
