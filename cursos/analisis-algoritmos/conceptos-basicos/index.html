01

Definición

Un algoritmo es un método para resolver un problema

El material de clase presenta al algoritmo como un conjunto ordenado de pasos que, ejecutados correctamente, permiten obtener un resultado en un tiempo acotado. El diseño del algoritmo consiste en encontrar un método o procedimiento que resuelva el problema planteado.

Problema → algoritmo: primero se establece qué se desea resolver; después se construye una secuencia de pasos capaz de producir la solución.

Puede existir más de un algoritmo para resolver el mismo problema. Por eso, más adelante será necesario comparar no sólo si resuelven el problema, sino también qué tan eficientes son.

Distinción clave

Algoritmo no es lo mismo que programa

Un algoritmo expresa el método. Una implementación es una forma concreta de escribir ese método mediante instrucciones elaboradas por el programador.

Consecuencia

Un mismo algoritmo puede tener varias implementaciones.

02

Propiedades

¿Qué condiciones debe cumplir un algoritmo?

1Entradas y salidas

Debe quedar definido qué información requiere y qué resultado produce.

2Preciso

Los pasos y su orden no deben ser ambiguos.

3Determinista

Con la misma entrada debe producir el mismo resultado.

4Finito

Debe terminar después de un número finito de pasos.

5Efectivo

Cada acción debe poder realizarse en tiempo finito y lograr el efecto esperado.

Ejemplo de ambigüedad

El material usa una receta de cocina para mostrar que instrucciones como “añada una pizca” pueden no ser suficientemente precisas para una computadora.

04

Problemas de repaso

Aplicación conceptual

Son ejercicios sencillos para verificar que las definiciones se distinguen correctamente.

Problema 1Una instrucción dice: “agrega una cantidad pequeña de sal”. ¿Qué propiedad está en riesgo?+
1
Identifica el problema

“Cantidad pequeña” puede interpretarse de varias maneras.

2
Conclusión

La propiedad comprometida es la precisión: la instrucción debe indicar sin ambigüedades cómo actuar.

Problema 2Para ordenar un arreglo, identifica una entrada y una salida.+
1
Entrada

El arreglo con los elementos que se desean ordenar.

2
Salida

Los mismos elementos organizados de acuerdo con el criterio de ordenamiento.

Problema 3Dos programas en lenguajes diferentes siguen el mismo método para resolver un problema. ¿Son dos algoritmos?+
1
Distingue niveles

Si ambos programas siguen el mismo método lógico, comparten el algoritmo.

2
Conclusión

Son dos implementaciones del mismo algoritmo.

Problema 4Un procedimiento tiene entradas, salidas y pasos claros, pero puede continuar indefinidamente. ¿Es un algoritmo?+
1
Revisa las propiedades

Falla la condición de terminar tras un número finito de pasos.

2
Conclusión

Según el material, no cumple la propiedad de finitud.
