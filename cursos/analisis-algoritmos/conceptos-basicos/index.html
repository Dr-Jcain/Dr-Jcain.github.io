Conceptos básicos de algoritmos

Un algoritmo especifica, sin ambigüedad y en un número finito de pasos, cómo transformar datos de entrada en un resultado. Antes de estudiar eficiencia y complejidad es necesario distinguir con precisión problema, algoritmo e implementación.

01

Definición

¿Qué es un algoritmo?

Algoritmo: conjunto ordenado y finito de pasos que, ejecutados correctamente sobre unos datos de entrada, permiten obtener un resultado.

El algoritmo describe la solución lógica de un problema. Su definición no depende de un lenguaje de programación particular ni de una computadora específica.

Para diseñarlo se parte del problema, se determinan los datos necesarios, se establece la secuencia de operaciones y se define el resultado que debe producirse.

Dos ideas distintas

Problema y algoritmo no son lo mismo

El problema establece qué se quiere resolver. El algoritmo especifica los pasos que producen la solución.

Importante

Un mismo problema puede admitir varios algoritmos diferentes. Después será posible compararlos por su eficiencia.

02

Propiedades

Condiciones que debe satisfacer un algoritmo

1Entradas y salidas definidas

Debe conocerse qué información recibe y qué resultado debe producir.

2Preciso

El orden y la ejecución de los pasos deben estar especificados sin ambigüedades.

3Determinista

Para la misma entrada debe producir el mismo resultado.

4Finito

Debe terminar después de un número finito de pasos.

5Efectivo

Cada paso debe poder realizarse en tiempo finito y producir el efecto indicado.

Precisión

Una instrucción como “añade una cantidad pequeña” es ambigua porque no establece una cantidad exacta. En un algoritmo, cada instrucción debe indicar claramente qué operación realizar.

03

Distinción fundamental

Problema, algoritmo e implementación

Problema

Describe la tarea que debe resolverse y los resultados esperados.

→
Algoritmo

Define la secuencia lógica de pasos que resuelve el problema.

→
Implementación

Expresa ese algoritmo como instrucciones concretas ejecutables por una computadora.

Varios algoritmos para un problema

Un problema puede resolverse mediante algoritmos distintos. Por ejemplo, un conjunto de datos puede ordenarse mediante diferentes algoritmos de ordenamiento.

Varias implementaciones de un algoritmo

La misma secuencia lógica puede implementarse de maneras distintas sin cambiar el algoritmo que se está ejecutando.

04

Ejemplo guiado

Algoritmo para obtener el mayor de dos números

MayorDeDos(a, b)Pseudocódigo
Entrada: a, b

Si a ≥ b entonces
    mayor ← a
Si no
    mayor ← b
FinSi

Salida: mayor

Este ejemplo permite revisar las propiedades sin introducir todavía análisis de complejidad.

Entrada/salida

Recibe dos números y devuelve uno.

Precisión

Cada decisión y asignación está definida.

Determinismo

La misma pareja de entrada produce la misma salida.

Finitud

La secuencia termina tras ejecutar una condición y una asignación.

Efectividad

Comparar y asignar son operaciones realizables.

Problemas de repaso

Aplicación de las definiciones

El objetivo es reconocer los conceptos con precisión antes de iniciar el análisis de eficiencia.

Problema 1Un algoritmo recibe tres números y debe devolver el menor. Identifica entrada y salida.+
1
Entrada

Los tres números que serán comparados.

2
Salida

El menor de los tres números.

Problema 2La instrucción “repite varias veces la operación” aparece dentro de un algoritmo. ¿Qué debe corregirse?+
1
Problema

“Varias veces” no fija un número de repeticiones ni una condición de terminación.

2
Corrección

Debe indicarse un número exacto de repeticiones o una condición precisa que determine cuándo detenerse.

Problema 3Un procedimiento tiene pasos claros, pero continúa indefinidamente. ¿Qué propiedad no satisface?+
1
Definición

Un algoritmo debe terminar después de un número finito de pasos.

2
Resultado

No satisface la propiedad de finitud.

Problema 4Para un problema de ordenamiento se proponen dos secuencias lógicas diferentes que ordenan correctamente los mismos datos. ¿Qué representan?+
1
Problema común

Ambas secuencias buscan resolver la misma tarea: ordenar los datos.

2
Conclusión

Representan dos algoritmos distintos para resolver el mismo problema.
